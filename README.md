# Gemstone AI API 💎

AI-powered gemstone identification API for [gemdistrict.art](https://gemdistrict.art) — built with Flask & TensorFlow, deployed on Render.

## 🚀 Features

- Upload image → get gemstone prediction + confidence
- Works with any frontend (HTML/JS, React, Vue, etc.)
- Easy to deploy on Render (free tier supported)
- Model can be retrained and updated anytime
